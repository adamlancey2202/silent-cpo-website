Global blog & social preview image
==================================

Add your generated artwork here as:

  blog-og-default.webp

Recommended size: 1200 × 630 px (Open Graph / LinkedIn / X).

PNG also works — if you use PNG, rename the constant in
src/lib/blog-media.ts (BLOG_OG_PUBLIC_PATH) or save as .webp.

Optional later: host on Cloudflare R2 and set BLOG_OG_IMAGE_URL on Vercel
(see docs/R2_STORAGE.md).
